# Math for Tech — Quiz 2 Study Hub

A collection of beginner-friendly notes and practice pages for Math for Tech Quiz 2.

## Study Topics

1. Indefinite and definite integrals
2. Improper integrals
3. First-order differential equations

## Pages

- [`index.html`](index.html) — Main landing page
- [`quiz-2-study-guide.html`](quiz-2-study-guide.html) — Complete Quiz 2 roadmap
- [`integration-and-derivatives-notes.html`](integration-and-derivatives-notes.html) — Integration and differentiation notes
- [`question-1-integrals.html`](question-1-integrals.html) — Question 1 lessons and practice
- [`question-2-improper-integrals.html`](question-2-improper-integrals.html) — Question 2 lessons and practice
- [`question-3-first-order-differential-equations.html`](question-3-first-order-differential-equations.html) — Question 3 lessons and practice
- [`quiz-2-study-guide.md`](quiz-2-study-guide.md) — Markdown version of the study guide

## Features

- Step-by-step explanations
- Worked examples
- Practice questions with hidden solutions
- Study checklists with locally saved progress
- Links between all study pages
- Responsive, distraction-free layouts
- Custom mathematical landing-page background

## Open Locally

Download or clone the repository, then open `index.html` in a web browser.

```bash
git clone https://github.com/dashaneka/math-for-tech-quiz-2.git
cd math-for-tech-quiz-2
```

The original lecture PDFs are intentionally excluded from this repository. The HTML pages may contain lecture links intended for the local study folder where those PDFs are available.

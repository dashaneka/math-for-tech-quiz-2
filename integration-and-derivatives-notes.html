01

Derivative and integration

They are different operations, but they work in opposite directions.

Differentiation
Power goes downd/dx (x3) = 3x2

Finds the rate of change or slope of a function.

Integration
Power goes up∫ 3x2 dx = x3 + C

Finds the original function from its derivative.

Central idea: integration is reverse differentiation. If differentiating \(x³\) gives \(3x²\), then integrating \(3x²\) gives \(x³+C\).

Why differentiation appears in integration

We use differentiation knowledge to recognize an antiderivative, to check an answer, and to find du during substitution.

Recognized/dx (x2) = 2x
Reverse it∫ 2x dx = x2 + C

The chain rule

For a function inside another function, differentiate the outside and then multiply by the derivative of the inside.

Chain ruled/dx [f(g(x))] = f′(g(x)) · g′(x)

03

What is an antiderivative?

A function whose derivative gives the original function.

The question you ask

To find the antiderivative of \(3x²\), ask: Which function produces \(3x²\) when differentiated?

Derivatived/dx (x3) = 3x2
Antiderivative∫ 3x2 dx = x3 + C

Why we add +C

The derivatives of \(x³\), \(x³+4\), and \(x³−10\) are all \(3x²\), because constants disappear during differentiation.

d/dx (C) = 0   ⇒   ∫ f(x) dx = F(x) + C

The letter \(C\) represents every possible constant.

04

Indefinite or definite?

Look for numbers above and below the integral symbol.

Indefinite integral
∫ f(x) dx

There are no limits.

The answer is a function.

Always include +C.

Definite integral
∫ab f(x) dx

It has lower limit \(a\) and upper limit \(b\).

Find an antiderivative, then calculate \(F(b)−F(a)\).

Do not include +C in the final answer.

Quick rule: no limits → indefinite → \(+C\). Limits present → definite → upper value minus lower value.
05

Basic integration rules

Increase the power, divide by the new power, and add +C.

Power rule · n ≠ −1∫ xn dx = xn+1/(n+1) + C

How to use the power rule

  1. Identify the current power \(n\).
  2. Increase it by one: \(n+1\).
  3. Divide by the new power.
  4. Keep any coefficient and simplify.
  5. Add \(+C\) for an indefinite integral.

06

Substitution and the meaning of du

Replace the inside function and its derivative as one complete package.

Why we use u and du

The letter \(u\) is only a temporary name for the inside function. The symbol \(du\) represents the derivative of that inside function multiplied by \(dx\).

Inside functionu = g(x)
Its differentialdu = g′(x) dx

If you choose \(y\) instead of \(u\), you use \(y\) and \(dy\). The letter does not matter; consistency does.

The complete replacement

Core exampleEvery symbol replaced
∫ 2x(x² + 3)4 dx
Chooseu = x² + 3
Differentiatedu/dx = 2x, so du = 2x dx
Replace(x² + 3)4 → u4 and 2x dx → du
∫ u4 du = u5/5 + C
Answer: (x² + 3)5/5 + C
Do not write only \(du=2x\). The complete statement is \(du=2x\,dx\). The \(dx\) changes to \(du\) when the integration variable changes from \(x\) to \(u\).

Substitution method

  1. Choose \(u\) as the inside expression.
  2. Differentiate it to find \(du\).
  3. Match the derivative-times-\(dx\) part of the original integral.
  4. Rewrite the entire integral using only \(u\) and \(du\).
  5. Integrate with respect to \(u\).
  6. Replace \(u\) with its original expression and add \(+C\).
Solved togetherExact derivative match
∫ 2x(x² + 5)3 dx
u = x² + 5,   du = 2x dx
∫ u³ du = u⁴/4 + C
Answer: (x² + 5)⁴/4 + C
Solved togetherAnother exact match
∫ 3x²(x³ + 4)5 dx
u = x³ + 4,   du = 3x² dx
∫ u⁵ du = u⁶/6 + C
Answer: (x³ + 4)⁶/6 + C
Solved togetherExtra constant outside
∫ 6x(x² + 1)² dx
u = x² + 1,   du = 2x dx
6x dx = 3(2x dx) = 3du
3∫u² du = 3(u³/3) + C = u³ + C
Answer: (x² + 1)³ + C
07

Integration by parts

Use it for a product when one function becomes simpler after differentiation.

Integration by parts∫ u dv = uv − ∫ v du

How to choose the parts

For \(∫xeˣdx\), choose \(u=x\) because differentiating \(x\) makes it simpler: \(x→1\). Choose \(dv=eˣdx\) because integrating \(eˣ\) is easy: it remains \(eˣ\).

Solved togetherProduct x · eˣ
∫ xex dx
Chooseu = x,   dv = ex dx
Finddu = dx,   v = ex
Formulauv − ∫v du
= xex − ∫ex dx
= xex − ex + C
Answer: ex(x − 1) + C

Exponential facts used here

Exactly eˣd/dx(ex) = ex
∫exdx = ex + C
Exponent axd/dx(eax) = aeax
∫eaxdx = eax/a + C

For example, \(∫e^{-x}dx=-e^{-x}+C\), because the derivative of \(-x\) is \(-1\).

08

Definite integrals

Find the antiderivative first, then calculate upper minus lower.

Fundamental Theorem of Calculus∫ab f(x) dx = [F(x)]ab = F(b) − F(a)

What the bracket notation means

\([F(x)]ₐᵇ\) is only a shorter way to write \(F(b)−F(a)\). Put the upper number into every \(x\), put the lower number into every \(x\), then subtract.

Worked exampleFundamental Theorem
∫02 (3x² + 1) dx
AntiderivativeF(x) = x³ + x
UpperF(2) = 2³ + 2 = 10
LowerF(0) = 0³ + 0 = 0
Answer: F(2) − F(0) = 10
Solved togetherPolynomial definite integral
∫13 (2x + 1) dx
F(x) = x² + x
F(3) = 3² + 3 = 12
F(1) = 1² + 1 = 2
Answer: 12 − 2 = 10

Definite integral with substitution

When changing from \(x\) to \(u\), you may also change the limits. Put each old \(x\)-limit into the equation \(u=g(x)\).

Solved togetherChange the limits
∫01 2x(x² + 1)³ dx
u = x² + 1,   du = 2x dx
x = 0 → u = 1;   x = 1 → u = 2
∫12 u³ du = [u⁴/4]12
Answer: 16/4 − 1/4 = 15/4
Solved togetherA negative definite integral
∫02 (x − 2) dx
F(x) = x²/2 − 2x
F(2) = 2 − 4 = −2;   F(0) = 0
Answer: −2 − 0 = −2
A definite integral measures signed area. An answer can be negative when the graph lies below the \(x\)-axis.
Solved togetherThe logarithmic form
∫1e 1/x dx

ln(e) = 1 and ln(1) = 0
Answer: 1 − 0 = 1

Common mistakes to avoid

These small details often decide whether an answer receives full marks.

Forgetting +CAdd it to every indefinite integral.
Adding +C to a definite answerDo not include it after evaluating limits.
Writing du = 2xWrite the complete expression: du = 2x dx.
Mixing variablesAfter substitution, the integral should contain only u and du.
Lower minus upperThe order is always upper value minus lower value.
Missing parenthesesUse F(b) − F(a), especially when F(a) is negative.
Using the power rule for 1/xThe answer is ln|x|+C, not x⁰/0.
Thinking 2x = x²They are not equal; x² is the antiderivative of 2x.
Integrating a product separatelyIn general, ∫fg dx is not (∫f dx)(∫g dx).
Ignoring a negative resultA definite integral may be negative because it measures signed area.

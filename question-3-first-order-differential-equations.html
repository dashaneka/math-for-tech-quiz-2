Quiz 2 · Question 3

Find the function from its rate of change.

A differential equation tells you how \(y\) changes. Your task is to recover \(y\), first as a family of solutions and then—when given an initial condition—as one particular solution.

Main decision: Can you separate the \(x\)-terms and \(y\)-terms? If yes, use separation. If the equation has the form \(y′+P(x)y=Q(x)\), use an integrating factor.
01

What is a differential equation?

An equation containing an unknown function and one or more of its derivatives.

General first-order equationdy/dx = f(x, y)

Three equivalent notations

dy/dx = f(x,y)
y′ = f(x,y)

Both mean “the derivative of \(y\) with respect to \(x\) equals \(f(x,y)\).”

Why “first order”?

The highest derivative present is the first derivative \(y′\). There is no \(y″\), \(y‴\), or higher derivative.

What are we finding?

A function \(y(x)\) whose derivative satisfies the equation.

Example: \(y′=2x\). We ask, “Which function has derivative \(2x\)?” The answer is \(y=x²+C\).
02

Solutions and initial conditions

A general solution has \(C\); an initial condition selects one value of \(C\).

General solution
y = x² + C

A family of possible solutions.

Particular solution
y = x² + 3

One solution after an initial condition determines \(C\).

Initial-value example Use the given point
y′ = 2x,   y(0) = 3
Integratey = x² + C
Use y(0)=33 = 0² + C, so C = 3
Particular solution: y = x² + 3

How to verify a solution

Differentiate the proposed \(y\), then substitute \(y\) and \(y′\) into the original equation. If both sides match, it is a solution.

Proposed solutiony = x² + 3
Differentiatey′ = 2x
03

Choose the solving method

Recognizing the form is the most important first step.

Separable
dy/dx = g(x)h(y)

You can move all \(y\)-terms beside \(dy\) and all \(x\)-terms beside \(dx\).

First-order linear
y′ + P(x)y = Q(x)

\(y\) and \(y′\) appear only to the first power and are not multiplied together.

Before solving a linear equation, divide when necessary so the coefficient of \(y′\) is exactly \(1\). Only then identify \(P(x)\) and \(Q(x)\).
04

Separable equations

Separate the variables, integrate both sides, and then use the initial condition.

Starting formdy/dx = g(x)h(y)
After separation1/h(y) dy = g(x) dx

Separable-equation method

  1. Move every \(y\)-term to the \(dy\) side.
  2. Move every \(x\)-term to the \(dx\) side.
  3. Integrate both sides.
  4. Simplify and solve for \(y\), when possible.
  5. Use the initial condition to determine \(C\).
  6. Differentiate or substitute to check the solution.
Worked example Separable initial-value problem
dy/dx = 2xy,   y(0) = 3
Separate(1/y) dy = 2x dx
Integrate∫(1/y)dy = ∫2x dx
ln|y| = x² + C
Exponentiatey = Cex²
Use y(0)=33 = Ce0, so C = 3
Particular solution: y = 3ex²
When \(\int 1/y\,dy=\ln|y|\), exponentiating turns the additive constant into a multiplicative constant: \(y=Ce^{(\cdots)}\).

First-order linear equations

Put the equation in standard form before doing anything else.

Standard formy′ + P(x)y = Q(x)

How to recognize a linear equation

AllowedNot linear
y′ + x y = exy′ + y² = x
x y′ + 2y = 1y y′ = x
y′ − (3/x)y = xy′ + sin(y) = x
Lecture 12 · Standard form Divide and move terms
x y′ = x² + 3y,   x > 0
Divide by xy′ = x + (3/x)y
Move y-termy′ − (3/x)y = x
P(x) = −3/x and Q(x) = x
The sign belongs to \(P(x)\). In \(y′−(3/x)y=x\), the function is \(P(x)=−3/x\), not \(+3/x\).
06

The integrating factor

A multiplier that turns the left side into one product derivative.

Integrating factorμ(x) = e∫P(x)dx
After multiplying(μy)′ = μQ

Linear-equation method

  1. Write the equation as \(y′+P(x)y=Q(x)\).
  2. Identify \(P(x)\) and calculate \(\mu=e^{\int P(x)dx}\).
  3. Multiply every term in the equation by \(\mu\).
  4. Rewrite the left side as the product derivative \((\mu y)′\).
  5. Integrate both sides: \(\mu y=\int\mu Q\,dx+C\).
  6. Divide by \(\mu\) and apply any initial condition.
Worked example Linear initial-value problem
y′ + y = ex,   y(0) = 1
IdentifyP(x)=1,   Q(x)=ex
Factorμ=e∫1dx=ex
Multiplyexy′ + exy = e2x
Product(exy)′ = e2x
Integrateexy = (1/2)e2x + C
Solve for yy = (1/2)ex + Ce−x
Use y(0)=11 = 1/2 + C, so C = 1/2
Particular solution: y = (ex + e−x)/2
07

Slope fields

A visual map of the slopes prescribed by \(y′=f(x,y)\).

How to read one

At each point \((x,y)\), calculate \(f(x,y)\). Draw a tiny line segment with that slope. A solution curve follows these segments without crossing against their direction.

If y′ > 0

The small segment rises from left to right.

If y′ < 0

The small segment falls from left to right.

If y′ = 0

The small segment is horizontal.

Larger |y′|

The small segment is steeper.

A slope field does not give one solution. The initial condition selects the one solution curve passing through the given starting point.
08

Euler’s method

Use the current slope to take a small numerical step.

Next x-valuexn+1 = xn + h
Next y-valueyn+1 = yn + h f(xn,yn)
Worked example Two Euler steps
y′ = x + y,   y(0)=1,   h=0.1
Startx₀=0, y₀=1, slope=0+1=1
Step 1x₁=0.1, y₁=1+0.1(1)=1.1
New slopef(0.1,1.1)=0.1+1.1=1.2
Step 2: x₂=0.2, y₂=1.1+0.1(1.2)=1.22
Always calculate the slope using the current point before moving to the next point.
09

The Question 3 exam method

Identify the equation type before choosing any formula.

  1. Read the equation: identify \(y′\), \(x\), \(y\), and any initial condition.
  2. Classify: directly integrable, separable, or first-order linear?
  3. Solve: separate variables or calculate the integrating factor.
  4. Integrate carefully and include the constant \(C\).
  5. Use the initial condition to find \(C\), if one is provided.
  6. Check by differentiating and substituting into the original equation.
